# Security reporting

Report suspected vulnerabilities through this repository's GitHub private vulnerability reporting interface. Do not include credentials or private project files in public issues.

The supported candidate is 0.1.0. Installations execute npm/native parser install scripts. Default graph builds are structural; explicitly selected deep summaries may send source context to the configured provider. See docs/DEPENDENCIES.md and THIRD-PARTY-NOTICES.md for runtime and provenance boundaries.

Skills are instructions, not process isolation or access-control enforcement. Preserve host permissions and review external writes, hook installation and application changes within the authorized scope.
